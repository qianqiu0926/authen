# AUTHEN 消费者首页修改说明（三类赛题场景汇入“发来看看”）

日期：2026-10-20
范围：仅消费者网页 APP 首页（百宝箱 / Toolbox）。企业管理端、线上发布、原生 iOS 均未改动。

## 一、改了什么

在保留原有视觉（奶油色 `--paper/--white`、哑光黑文字、口红红 `--red`、402×874 手机比例）和原有“发来看看”流程的前提下，首屏 hero 下方新增一组“从哪里发来？”场景入口，共三张卡片，全部有真实交互，点击后统一汇入现有 `smart` 弹窗（SmartIntake，标题“发来看看”）：

| 卡片 | 点击后的真实行为 |
|---|---|
| 种草内容 | 打开“发来看看”，预选重点“功效靠谱吗？”，顶部显示粉色引导条：贴笔记或商品链接，正文和功效承诺一起核对 |
| 评论区 | 打开“发来看看”，预选重点“好评真实吗？”，顶部显示薄荷色引导条：贴商品/笔记链接读公开好评，也可直接贴几条评论 |
| 图片 / 视频 / 音频 | 打开“发来看看”，顶部显示米色引导条，并自动弹出系统选文件窗口（图片/视频/音频）；不弹时也可点“放入素材” |

原 hero 上的“链接、截图、笔记，发来看看”主入口保持原样，直接打开同一个弹窗，不显示场景引导条。弹窗内粘贴链接、放入素材、录音、重点选择、提交“帮我看看”等既有流程一律未改。

页面不展示任何置信度、概率或内部编码；消费者文案全部为大白话。
