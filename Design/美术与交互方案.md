# AUTHEN

美妆内容鉴真。先完成美术，再做 iOS，最后做网页。

## 一眼看上去

像一本会动的美妆杂志。奶白纸面、墨黑、大面积留白、一抹口红红。排版有大小和倾斜变化，按钮像梳妆台上的小物件。

角色沿用你的手绘：黑色短发、红色猫眼镜、利落红西装、黑裙。她有主见、好奇、有一点俏皮。不要换成通用卡通小助手。

碎纸机参考图 1 的“放进去、变出来”。造型改成与角色搭配的奶白机身、黑色进纸口、红色小开关，带少量金属边。只碎掉屏幕上的素材卡片，原文件始终保留。

## 页面

| 页面 | 主要画面 | 必要文字 | 用户能做什么 |
|---|---|---|---|
| 首页 | AUTHEN 字样在人物身后；角色在梳妆台前；输入物件散落排列 | 图片、视频、文字、链接；试一下 | 选素材；摸摸角色；打开历史 |
| 素材台 | 用户实际素材变成一张可拖动的小卡；碎纸机露出入口 | 拖进来；换一份 | 拖入或点按钮送入；补充文字 |
| 分析中 | 卡片进纸；纸条落下又聚成报告；角色低头、转眼、扶眼镜 | 看内容 → 查资料 → 整理中 | 取消；失败时拿回卡片重试 |
| 结果 | 报告从机器弹出；人物侧身托住；口红笔迹写出短结论 | 有疑点／查到了／还差一点；看依据 | 拉开报告；点击疑点；补材料 |
| 报告详情 | 素材、可疑位置、查到的商品资料、原文与来源 | 哪里、为什么、接下来 | 放大原图；看对照；打开出处 |
| 档案 | 一叠略微错位的报告卡，像桌上的纸页 | 档案；日期 | 翻看、导出、删除 |
| 设置 | 从衣服标签般的小入口打开简洁面板 | 声音、动效、资料保存 | 开关音效与动效；删除资料 |

正文默认折叠。结果页先给一句结论与 2–3 条关键发现；细节点开再看。

## 角色怎么跟人玩

| 操作 | 角色反应 | 与功能的关系 |
|---|---|---|
| 鼠标移动／手指在舞台滑动 | 眼睛朝指针转；头和肩轻轻跟随 | 视线引导到当前素材或按钮 |
| 点击眼镜 | 扶眼镜、眨眼 | 打开一次“试一下”的样例入口 |
| 拖动手臂 | 手臂轻拉，松开回弹 | 把手中的素材带向进纸口 |
| 双指捏角色 | 人物轻微压扁或拉长，松开复原 | 有触感反馈；不改变报告结论 |
| 拖素材经过角色 | 她先看素材，再看碎纸机 | 明确“把它放这里”的动线 |
| 分析开始 | 收回手、低头看纸、扶眼镜 | 配合真实步骤，不演假进度 |
| 报告完成 | 抬手递出报告 | 用户拉起报告就展开详情 |
| 资料不够／失败 | 歪头并把卡片递回来 | 直接出现“再加一张”或“重试” |

鼠标悬停用在 iPad 指针和网页。iPhone 用触摸追踪、拖动、双指捏合；Simulator 也可用鼠标拖拽和模拟双指操作验证。

## 碎纸到报告

1. 选择真实素材；缩略图上保留原内容。
2. 拖入进纸口，卡片弯曲、逐渐被吞入；轻触按钮也能完成同样操作。
3. 纸条从机器下方落下。分析未完成时，角色看资料，纸条保持轻动。
4. 拿到真实检查结果后，纸条聚成纸页；报告弹出。
5. 点报告上的疑点，直接进入对应原图、文字或视频时间点。

出错时卡片退回。取消立即停止本次任务。不能只播放定时动画后无条件给固定结论。

## 美术要交付的资产

| 资产 | 要求 | 用途 |
|---|---|---|
| 首页、分析中、结果、详情的完整视觉稿 | 同一人物、同一色系；先用于确定完整画面 | 开发对照 |
| 人物主形象 | 原手绘角色延展；头、眼睛、手、身体能拆开 | 注视、转头、伸拉、捏动 |
| 查看资料、递报告、疑惑三种姿势 | 身份、服装、比例保持一致 | 分析、结果、失败状态 |
| 碎纸机 | 机身、进纸口、前盖分层；入口与出口位置固定 | 卡片正确穿插遮挡 |
| 四个梳妆台物件 | 口红、粉饼、睫毛膏、香水；同一套材质 | 图片、视频、文字、链接入口 |
| 报告纸页 | 轻微纸纹，边角自然；正文保持代码排版 | 可拖动、可展开的报告 |
| 字标与应用图标 | AUTHEN 拼写准确；缩小后仍能认出 | App 与网页统一品牌 |

Image 2 负责角色与物件的最终美术。文字、按钮、进度、真实素材和报告内容用原生界面实现，保持可点击、可读和可更新。

## 颜色与字

- 纸白 `#F7F2EB`；墨黑 `#191817`；口红红 `#B52B32`。
- 辅助暖灰 `#A69C93`；少量香槟金 `#BDA486`。
- AUTHEN 使用有时装感的衬线字。操作提示使用清楚的系统中文字体。
- 所有关键操作有文字提示；不依赖颜色或动画才能操作。

## 与赛题的连接

用户带来美妆图片、文字或视频。产品读内容、找疑点、查可用资料，再展示依据和下一步。样例明确标“示例”；实际上传与样例走各自真实的数据来源。

不把“像 AI”直接写成“假”。也不凭图片给实物开正品证明。页面不放长说明，只在相关结论旁写清缺什么。
