# 种草验真课

定位：用户边学妆，边学会看懂种草内容里的证据。最终判断对象是原帖中的说法和素材。

| 口红试色：换到自然光，还一样吗？ | 薄涂、厚涂、渐变唇 | 色号与拍摄条件是否一致；有没有把调色效果说成产品效果 |

## “＋”建议怎么做

动态页的“＋”打开两个选择：“发动态”和“跟着验”。教程详情也直接放“跟着验”，自动带入当前内容。

1. 选一句要核对的话。APP 从标题、正文、评论、字幕和口播中整理候选，例如“原相机直出”“只用一支口红”。用户可以改选。
2. 做一个小判断。对照原文和画面，点出可疑的词句、局部画面或时间点。每次只练一个判断。
3. 可选“镜子跟练”。列出 2—3 步，用唇部、脸颊等定位提示帮助用户对准同一区域，记录同光线、同角度的前后画面。相机只做位置辅助和过程记录，不给长相打分。
4. AI 整理依据。核对原话、画面、口播、来源记录，指出具体冲突及位置。没有充分依据就显示“还不能确定”，说明缺少什么。
5. 收下一张卡。卡片只留结论、依据、建议。用户可收藏，或自愿分享带来源的练习心得；完成并正确理解依据后获得小叶子。

镜子可以跳过。没有拍摄条件的用户仍能完成鉴真练习。

## 首个演示：这张唇妆图，真的“原相机直出”吗？

使用团队自制、取得授权的素材，不给真实博主捏造一个造假案例。

- 原始样本：团队拍摄的同一张唇妆图与原视频。
- 对照样本：在复制图中局部改唇色或生成唇部，保留编辑过程和准确区域记录；配上明确标为练习的“原相机直出”文案。
- 用户：点出要留意的唇部和“原相机直出”这句话。
- Agent：核对原话与来源、编辑记录；结合实际运行的检测能力，展示具体位置和依据；说明是“描述与制作记录不符”。
- 建议：查看原图或无滤镜试色；发布时如实标注编辑方式。
- 结果卡示例：练习样本有唇部编辑记录；与“原相机直出”的说法不一致。依据来自本题制作记录，不是肉眼猜测。

需要同时安排诚实标注的 AI 素材、普通调光和未修改样本，避免把“有编辑”“AI 生成”直接等同于欺骗。奖励依据判断过程，不按抓出多少“假内容”发奖励。

## 与赛题二的对应

- 多模态：文字与评论中的说法，和图片、视频画面、字幕及音频口播一起核对。
- 合成 / 篡改：有明确制作记录的原始、局部修改和生成样本，用于验证检测结果。普通跟妆成败不算伪造证据。
- 可解释：指出具体句子、画面区域和时间点，并允许查看来源。
- Agent 闭环：读内容 → 找具体冲突 → 说明依据与不确定处 → 给用户下一步 → 留下可追溯的结果卡。

## 优先级与边界

建议先做“唇妆色差”和“底妆滤镜”两关。初版先完成真实素材与自制对照样本、判断练习、结果卡，再接镜子定位跟练。它可以丰富体验，但不是识别伪造的必要条件。

当前已完成：真实参考内容导入、动态分类、来源与封面、观察题。

当前是设计方案、尚未实现：＋里的跟练任务、镜子节点指引、标准化拍摄、自动发放练习奖励、图片 / 音视频专项伪造检测及其可靠概率。已有 AI 内容分析继续可用，不能把它包装成已经接入专项鉴伪模型。

待定两项：
- 镜子画面建议默认仅保存在本机，由用户另行决定是否上传或分享。
- 练习积分建议用于装扮和学习权益；品牌实物兑换仍取决于正式活动规则。
