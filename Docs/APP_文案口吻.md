# APP 文案口吻

直接回答用户关心的事，像懂美妆的朋友帮忙看笔记。常用试色、薄涂、厚涂、卡粉、磨皮、种草；不强行喊姐妹、宝子，也不堆黑话。

| 原来的说法 | 现在的说法 |
| --- | --- |
| 看来源，别只凭感觉 | 点开原帖，找找制作说明 |
| 先确认产品版本 | 先看是不是同一款 |
| 查适用条件与依据 | 先看看敏感肌的试用反馈 |
| 资料没有支持这项承诺 | 只写了保湿，没写能变白 |
| 无法确认图像是否经过篡改 | 这张图修没修，现在还看不出来 |
| 需核对浓度及标注来源 | 笔记写10%，瓶身写2%，两个数字对不上 |

覆盖：游戏题目与答案、小课堂提示、资料卡、输入提醒、设置说明，以及 AI 新生成的答案。旧的固定模板在显示时兼容转换；本机已有卡片的说明也已整理。原文引用、商品名、数字和来源摘录不改写。

结果先说哪里对不上，再给一个具体动作；不能确定就直说。没有把看不出来改成造假，也没有加入真假概率。

验证：19 项后端测试通过；13 项原生内容读取、原文保留和结果解析检查通过；游乐场和真实 AI 资料卡的两条界面流程通过。已在 Simulator 检查游戏文字排版和实际结果。真实接口回答保存在 QA/consumer-copy-live-answers.json 与 QA/consumer-copy-final-answers.json。
