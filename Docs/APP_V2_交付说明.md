# AUTHEN 消费者 APP · V2

原生 iOS APP，通过 `启动App.command` 打开 Simulator。企业管理网页本轮未改动。

## 页面与操作

| 位置 | 用户能做什么 |
|---|---|
| 百宝箱 | 提交图片、视频、文章、链接、音频、多条评论；文章和评论可附图。查看最近资料卡，进入游戏和小屋。 |
| 动态 | 分类浏览、搜索、喜欢、收藏、评论、发文字或图片动态；读取公开链接，编辑后发布；帖子可直接查一查。 |
| 我的 | 收藏的资料卡、查阅足迹、自己发布和收藏的动态；搜索已存资料。 |
| 资料卡 | 简短答案、原文数字对比、需留意的原话、下一步建议、实际读取的出处；收藏、补充内容；卡内查看原文、画面、原音和视频。 |
| 红眼镜助手 | 常驻 APP 内，可拖动、靠边，快速打开文字、图片、链接入口。 |
| 真假游乐场 | 知识消消乐：配对说法与做法。来源小侦探：区分有来源登记的照片与有制作记录的 AI 图片。 |
| 小叶子 | 每个挑战首次完成得 10 片，可兑换小屋装饰；记录余额和收支，重复通关不重复发奖。 |
| 3D 小屋 | 旋转房间和红眼镜人物，换樱桃红、奶油白、玫瑰粉配色，兑换绿植、口红摆件。 |

旧的素材投放台、核验进度、报告与证据页面已从应用入口和编译目标移除。旧源码归档在 `Design/ArchiveUI`，不在 APP 内展示。

处理中可切换页面。完成后显示“资料卡好了”，不强制跳离动态。失败时显示真实错误；AI 不可用时明确标为本机初查。

## 实际接通的判断流程

1. 文字和评论保留前后文；图片使用 iOS Vision 读取文字及位置。
2. 视频最多抽取 8 帧，保留时间点，可同时读取口播。
3. Simulator 用本机 faster-whisper small 转写音频，保留时间段；真机用系统语音识别。
4. DeepSeek 读取文字、图片、实际转写内容，找数字冲突、过度承诺、上下文遗漏等问题。
5. 按关键词读取指定公开资料页，覆盖防晒、护肤品试用、痤疮治疗；仅把实际读到的段落交给模型。
6. 服务端校验原话、数字、来源编号和位置；模型不能自行添加来源网址、框选位置或“99%真实”之类的分数。
7. 整理成可收藏的资料卡。个人提交不会自动变成社区帖子或游戏题目。

开源组件：[faster-whisper](https://github.com/SYSTRAN/faster-whisper) 用于本机转写；[Cheerio](https://github.com/cheeriojs/cheerio) 读取公开页面正文与作者元信息。图片/视频还使用原生 Vision、AVFoundation；3D 使用 SceneKit。

## 真实边界

- 动态是本机社区试用，示例逐条标注。发布、评论、收藏可保存并在重启后读取；尚未部署多用户社区和跨设备账号。
- 公开链接导入已实现，尚未批量爬取社交平台。需登录或有访问限制的帖子可能读不到，可提交截图。链接当前只读正文，不保证抓到所有图片和评论。
- 公开资料读取是指定来源的关键词检索，不是全网搜索，也不是欧莱雅内部知识库。
- 能发现内容冲突、提出疑点并引用资料；尚未部署 FakeShield、UniversalFakeDetect、AASIST 等专项模型，不能认证具体图片生成器、换脸、声音伪造或商品真假。
- AI 生成不等于内容骗人；游戏的来源答案来自素材登记。转写也可能听错，尤其是商品专有名词，可回听原音。
- 宠物只在 APP 内浮动。iOS 普通 APP 不能任意悬浮在其他 APP 上方；本轮尚未加入系统分享扩展。
- 小叶子与装饰兑换是本机闭环；真实品牌产品加价兑换、支付和履约未开放。企业无法读取个人画像。
- 真机服务地址、账号权限和生产部署尚未配置。本轮交付面向 Simulator。

## 本机运行

双击 `启动App.command`，启动本机服务、构建并打开 Simulator。密钥仍保存在项目外私密配置中，客户端不携带密钥。

语音环境已经安装。重建时用 Python 3.12 创建 `.venv-audio`，安装 `services/requirements.txt`，运行 `services/transcribe.py` 下载 small 模型。转写只读本地模型，临时音频处理后删除。

Node 测试在 `web` 运行 `npm test`；iOS 测试运行 AUTHEN scheme。音频集成测试需先启动本机服务。界面截图、实测结果和日志在 `QA`。
