# 后续鉴真服务接入

这份工程已经把输入、进度、结果、依据和后续操作连起来。正式参加鉴真能力评审前，还需要补上以下内容。

2026-10-15更新：DeepSeek官方文字与图片内容分析已经接入。服务端入口为`web/deepseek.mjs`，iOS入口为`RemoteReview.swift`；详情见[DeepSeek接入](DeepSeek接入.md)。下面的专项检测、真实品牌资料和复核能力仍待接入。

| 要接入的内容 | 用来做什么 | 页面已有的承接位置 |
|---|---|---|
| 图片检测服务 | 判断篡改、拼接、生成线索 | 原图标记、逐条疑点、检查范围 |
| 真实品牌资料 | 对照成分、用途与功效说法 | 出处标题、原文摘录、来源链接 |
| 视频检测与口播 | 定位可疑画面和语句 | 视频回放、时间点、覆盖范围 |
| 人工复核 | 处理不能自动判断的情况 | 当前提供补充资料和导出；团队后台待开发 |

每条依据需要包含：原话、为什么值得核对、来源、下一步。图片还要给出真实位置，视频还要给出时间点。没有来源时，继续使用「还差一点」或「需补充」，不要默认通过。

iOS 接入入口：`MediaReader.swift`负责读取材料，`RemoteReview.review`请求服务端产生`AnalysisReport`；`ContentReview.review`保留为明确标注的本机初查和示例。

网页接入入口：`src/media.ts`读取材料后请求`/api/review`；`src/review.ts`保留本机初查和示例。页面根据`analysisLabel`显示实际分析方式。

字段说明：`evidence` 是依据列表；`box` 为从图片左上角开始的位置与宽高，取值 0～1；`imageIndex` 指向对应图片；`seconds` 是视频秒数。来源保留标题、原文摘录与可打开的网址；示例标志需要一直保留。

模型密钥只放服务端。Image 2 当前仅用于制作美术，不能据此认为正式鉴真服务已经可用。
