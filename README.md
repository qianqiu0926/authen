# AUTHEN

美妆内容，查个明白。

已有原生 iOS 和消费者 APP 浏览器版。奶白、墨黑、口红红，沿用原人物与图标。公网入口展示百宝箱、动态、游乐场、我的，企业端暂不启用。电脑保留 402 × 874 手机内容尺寸，较矮窗口等比缩小；手机全屏适配。

## 直接打开

- **App：**双击 `启动App.command`，自动启动本机AI服务并运行模拟器；直接从Xcode运行时，先启动 `启动AI服务.command`。
- **网页 APP：**双击 `启动网页.command`。公网地址为 https://authen.classby.cn/authen/ ，支持六种输入、资料卡、动态、游戏奖励和 3D 小屋。
- **演示：**`QA/AUTHEN-iOS演示.mp4`；`QA/AUTHEN界面总览.jpg`。
- **需求表：**工作区「交付成果 / 赛题2_APP产品需求与功能梳理.xlsx」。

## 可以玩什么

2026-10-16 更新：百宝箱改为一个“发来看看”窗口，自动识别分享链接和实际内容类型。六宫格替换为鉴真成长树，完成查阅、收藏与学习任务可获 5 片叶子。公开正文、配图与评价按实际读取情况展示；受登录或平台限制时可补正文或截图。详见 `deployment/SMART-INPUT-RELEASE.md`。

1. 百宝箱：选择图片、视频、文章、链接、音频或评论，得到简洁的资料卡。
2. 动态：浏览原作者教程、搜索分类、喜欢收藏，也能在本机发帖和评论。
3. 游乐场：消消乐和来源小侦探，首次完成各得 10 片小叶子。
4. 我的：知识库、足迹、发布和收藏；进入 3D 小屋摆家具、换配色、保存装扮。
5. 小屋支持旋转视角、缩放、家具移动旋转、撤销和隐藏；叶子可换口红展台。

网页浮动助手可拖到两侧，也可接收拖入的素材。设置可关闭动效、轻触反馈、声音和 AI 分析。

## 当前能查到什么

- 真实图片：读取中英文文字，将图片和文字交由DeepSeek理解，提出需要核对的说法和图文冲突；同时跑本地图像取证（复制粘贴、重压缩差异、频域周期峰、噪声一致性、EXIF与编辑软件记录），给出可疑位置坐标。
- 真实视频：抽查最多8个画面及可读字幕，保留时间位置。网页还可转写浏览器能解码的音轨；无音轨或无法解码时会说明。
- 真实文字：按文字依据、上下文完整性、图文一致性、评论区真实性、商品真实性逐项核对，输出五档结论。
- 链接：尝试读取公开页面；受网络、登录或网页限制时，提示改用截图。
- 三种示例：有疑点、有资料对应、资料不足。素材和商品资料均由团队编写，页面明确标注。

**多Agent鉴真流水线与本地图像取证已接通；像素级篡改定位、声音克隆检测和官方品牌资料库尚未接入。**可选接入UniversalFakeDetect（OpenAI CLIP ViT-L/14）做生成图检测，未安装权重时明确标注未启用。AI关闭或失败时确定性检查照常出结果，报告写明缺什么；不提供无依据的真假概率或伪造热力图。

## 文件与数据

- iOS 资料卡和视频在本机保存，最多 50 份；网页保存在当前浏览器，最多 50 份。
- iOS 导出 PDF，并可调起系统分享；网页下载独立 HTML 报告，可用浏览器打开、打印成 PDF。
- 网页识字仍在本机进行；开启AI分析时，文字、图片和视频抽查帧会经服务端发送至DeepSeek。输入页和设置中有说明并可关闭；原音视频文件不传给DeepSeek。
- Image 2与DeepSeek密钥存放在工程外的私密配置中，不进入网页或安装包。后台在服务器内部监听，由 Nginx 提供 HTTPS 公网访问。

## 代码仓库导览

- `web/`：消费者端网页（React + Vite）与服务端。`web/pipeline/` 是鉴真流水线，`web/pipeline/grounding.mjs` 是主张与资料对照引擎，`web/pipeline/fuse.mjs` 是按规则算结论的融合层，`web/pipeline/agents.mjs` 是五个专职取证 Agent。
- `services/forensics.py`：本地图像取证（ELA、频域、噪声、复制粘贴、元数据），由 Node 侧按需调用，不常驻。
- `QA-140-report/`：140 条验收集的复算脚本、原始结果与两份 PDF 报告。复算命令：`node QA-140-report/scripts/eval_local.mjs`。
- `Docs/`：鉴真标准落地、算法流程、交付检查表。
- `Design/`：设计令牌与美术方案。
- `iOS/`：原生端源码，不含构建缓存。

2026-10-20 实测：140 条验收集严格通过 56.43%（79/140），归因与改造过程见 `QA-140-report/report_v21/report_v21.pdf`。该数字仅为构造验收集上的通过率，不代表真实世界鉴真准确率。
