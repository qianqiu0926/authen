# 链接与评论一起检查

日期：2026-10-16。版本：`20261016-link-comments`。

入口：https://authen.classby.cn/authen/ → 发来看看 → 粘贴分享链接。

## 用户流程

- 移除消费者独立的“评论区”素材类目，链接入口说明“正文 + 评论一起看”。无需用户批量复制评论。
- 页面能公开提供的正文、图片、评论一同读取，一次生成资料卡。
- 资料卡新增“评论区一起看”：已读取条数、纳入比较的条数、可疑话术占比，以及“话术可疑 / 有使用细节 / 暂难判断”三类数量。
- 展开可查看统计方法、重复原话和有具体体验的评论。随资料卡收藏并写入下载文件。
- 无可比较评论时显示未读取，不显示 0%；少于 10 条只展示数量，不计算占比。读取失败后可以补评论截图或文字。

## 统计与边界

- `comment-signals.mjs` 提供可重复的文字统计。比较规范化后的相同长句或高度相似长句，至少涉及 3 个不同可见昵称/账号才计入。短句赞同和简单“好用”不计入。
- 相似度使用字符二元组，最低句长、长度差和相似度阈值均限制误报；不是经过标注数据校准的水军分类器。
- 同一抓取记录去重，保留不同用户的相同话术；能通过公开字段确定的作者回复排除，读者回复保留并在卡片标明。
- 使用细节仅表示文字提到肤质、使用过程、感受等，不等于真实评价。其余评论为暂难判断，不按 `100%-可疑占比` 计算真实比例。
- 分母只使用本次实际读取并纳入比较的评论。读取上限从 20 条调整为最多 60 条，仍受约 6000 字预算和平台公开展示范围限制；不使用平台的“总评论数”作为分母。
- 帖子/商品不会因为附带评论就被改成评价类目。AI 同时收到正文和重新计算的评论线索，作为整体判断参考；不接受客户端自行填写的占比。评论必须逐字包含于已读文字中。
- 评论讨论不同话题、不涉及该商品，并不等于反驳正文；已加强模型说明，避免将不同话题硬解释为矛盾。
- 没有新增平台授权或绕过登录验证。淘宝、抖音等若不公开返回评论，仍不能获取全部评价；不承诺任何来源都可读，也不判定账号身份。
