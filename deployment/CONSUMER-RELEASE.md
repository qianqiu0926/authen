# 消费者 APP 浏览器部署

版本：20261015-232500-consumer。原企业端改为消费者 APP，后台与 HTTPS 配置沿用。

## 页面与尺寸

- 四个主页面：百宝箱、动态、游乐场、我的。
- 电脑内容尺寸为 402 × 874，外框为 414 × 886；窗口较矮时整体等比缩小。
- 手机全屏适配；底部导航固定，内容在 APP 内滚动。
- 复用原人物、图标和 YouTube 原图，保留原作者与链接。
- 3D 小屋支持旋转缩放、家具移动旋转、撤销、隐藏、重新放入、配色、保存和未保存提醒。

## 当前边界

- 这是原生 APP 体验的浏览器实现，不是 Swift 安装包。企业端暂不启用。
- 独立 IndexedDB 保存最多 50 份资料卡、动态、叶子和小屋；原生 APP、IP 入口与域名入口不自动同步。
- 动态发帖和评论仅本机可见，未接跨用户社交服务。助手只能在网页里悬浮。
- 视频可读音轨会转写，无法解码时说明未覆盖声音，可单独传音频。
- 已接 DeepSeek 内容分析，尚无专门的 AI 生图、图片篡改、换脸或合成声音检测，不给真假概率。

## 验证

- 23 项网页与后台测试通过，含手机比例、重复领奖、重复扣费、家具边界与碰撞。
- 桌面 1280 × 1000、1024 × 768 与手机 390 × 844 尺寸检查通过。
- 两个游戏首次共得 20 片叶子；重复通关不重复领取；口红展台扣 10 片。
- 绒面凳旋转 45 度并移动后保存，刷新保留；未保存离开会提醒。
- 真实数字核对、视频抽帧、资料卡收藏并刷新保留、本机动态发布通过。
- 公网音频上传、服务器转写和 DeepSeek 资料卡完整流程通过；HTTP、HTTPS 和状态接口正常。
- 构建文件已知 API 密钥扫描通过。日志为 consumer-tests.log。
- 线上尺寸实测保存在 consumer-viewport.json；桌面与手机截图同目录保存。Nginx、AUTHEN、EvoPi API 与原 IP 网站运行正常。
