# 分享链接兼容与读取范围修复

日期：2026-10-16。最终版本：`20261016-share-platforms-3`。

## 已实现

- 淘宝 `e.tb.cn` / `m.tb.cn` 短链接：安全解析页面中的字面跳转地址，继续读取商品页，不执行远端脚本。
- 支持网页刷新跳转、字面地址跳转；保留每次跳转的公开地址校验、总超时、跳转上限及循环检查。
- 抖音短链接展开后按作品 ID 读取公开手机分享页，支持视频与图文；解析内嵌 `_ROUTER_DATA`、`RENDER_DATA` 等公开数据。严格匹配 ID，跳过推荐作品，封面不当作视频已观看。
- 解析公开淘宝商品结构；商品摘要与完整正文分开标注。不将价格参数、评价数量当作真实价格或已读取评价。
- 新增 B 站、快手、拼多多、公众号、知乎、TikTok 平台识别；其他公开网页继续走通用正文提取。这些平台标签不代表每个平台每条链接均可完整读取。
- 支持 GBK 等旧中文编码，避免商品页乱码。
- 正确识别登录页、验证页、只提供“打开 App”的页面及无内容错误页，禁止把平台介绍当作正文。
- 输入失败后保留分享文字与附件。淘宝商品名、抖音作者/标题独立识别，去除分享命令和口令；可以选择“先看分享文案”，也可补图、正文或视频。
- 资料卡显式显示“仅分享文案”；原链接未读到时不会声称读过商品详情、评论、画面或口播。仅有标题时禁止因缺少全文而生成疑点。

## 两条用户链接的真实实测结果

### 淘宝

`https://e.tb.cn/h.jYiEfYeqgyLtQGS?tk=MnxuTthGltC`

短链接已展开到商品 `805128203224`。桌面请求返回登录跳转页，手机请求返回商品 App 页面/空壳；本机与服务器均未获取到商品详情或评论。API 正确返回 `APP_REQUIRED`，不会把通用购物平台介绍当作成功内容。

线上已走通：整段粘贴 → 淘宝商品识别 → 保留原文 → 先看分享文案 → 明确范围的资料卡。YSL 商品名称来自用户分享文字，不是抓取所得。

### 抖音

`https://v.douyin.com/Jz5Zj3ELoOA/`

短链接已展开到作品 `7670577114324631217`。用户正常浏览器能看到“来杯冷尹”的护肤视频及部分评论；服务器公开手机页面返回“抱歉出错了，请尝试在抖音内观看”，内嵌数据没有作品内容，API 正确返回 `CONTENT_UNAVAILABLE`。

直接公开详情接口返回 403；没有使用用户 Cookie、伪造签名或绕过验证。独立公开网页阅读服务的返回内容与目标视频不符，未接入产品。服务器隔离浏览器试验因 Chromium sandbox 启动失败停止，未禁用 sandbox 或改变系统保护；试验包已清理。

因此 **这两条链接的完整自动读取仍未打通**。目前交付的是平台与内容识别、公开页面适配、准确报错和可继续的补充流程；稳定读取受限内容仍需要可用的授权接口或独立、可靠的页面读取服务。没有承诺任意来源全部可读。
