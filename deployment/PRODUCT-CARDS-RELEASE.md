# 产品资料与官方选购

日期：2026-10-16；版本：`20261016-product-cards`。

入口：https://authen.classby.cn/authen/

## 原来的入口

- “我的小叶子 → 品牌兑换”原为“活动尚未开放”。小屋的兑换只购买数字装饰。
- 链接读取失败时的“打开商品”是用户原链接，不是经确认的官方渠道。
- 本次将产品链路放在鉴真结果内，未新增商城或单独产品页面。

## 新流程

提交文字、链接、图片可读文字或音视频转写 → 核对说法 → 资料卡内“产品与选购” → 产品介绍/买前功课 → 品牌官网或官网列出的购买渠道。

- 从可读原文匹配固定产品目录；不读取模型生成的购买地址，也不把解析出的商家自称“官方”当作官方渠道。
- 未能确定产品版本，先显示候选并让用户确认；只认出品牌时，显示品牌入口及原文名称线索。
- 多产品可同时显示；逐项确认、隐藏。可手动更正、补包装图；确认一个候选不会替其他候选作确认。
- 收藏与下载资料卡包含产品资料和链接。旧记录可自动匹配，用户更正保存在当前浏览器。知识库支持按产品/品牌名搜索。
- 商品识别和购买不改变原报告结论；部分已核实品牌资料可作为新分析的参考，明确标注“品牌官网说明”和整理日期。品牌自述不等于独立功效证据。
- 不从评论区的偶然产品提及生成正文商品推荐，不为团队演示材料显示购物卡。
