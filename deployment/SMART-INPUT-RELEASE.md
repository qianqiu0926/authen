# 2026-10-16：统一提交与鉴真成长树

版本：20261016-smart-input。消费者 APP 浏览器版；仍保持桌面 402 × 874 逻辑尺寸和手机全屏适配。

## 改动

- 首页移除六宫格，顶部只保留“发来看看”；同一窗口可输入文字、分享链接、评论，添加图片、视频、音频或录音，也能粘贴和拖入素材。
- 普通文字输入自动识别嵌入的分享链接，保留用户的问题，自动读取后送入鉴真。无需先选“链接”模式。链接可选择暂不读取，用补充正文或截图继续。
- AI 在同一次分析中先识别种草、评价、功效宣传、教程等实际内容类型，再按不同重点给出卡片。上传格式不等同于内容类型；评论截图可按评价分析。
- 成长树记录真实 AI 查阅、非示例资料卡收藏、游戏学习三个任务；完成后一次性获得 5 片叶子。任务完成记录保留，删除资料卡不回退成长，不重复领奖。
- 结果卡显示内容类型、检查重点，以及链接实际读到的正文、配图、评价数量。全文不可用时明确注明只读到标题与简介。
- 浮动助手在出现处理提示时上移，避免挡住“补充内容”。

## 链接读取

支持公开 HTML、JSON-LD 商品/文章/评价、小红书公开 noteDetailMap 正文与图片、明确的评价节点，以及常见懒加载和 Vue 图片地址。只解析数据，不执行页面脚本。短链接逐次检查并跟随公开跳转。

读取器最多读取 3 张相关配图、20 条且合计不超过约 6000 字的公开评价、约 7000 字正文；不把评价数量或评分当成评价内容。相同话术在不同评价中保留，不因为重复就判断刷单。

图片也做公开地址检查、重定向检查、类型和大小限制；屏蔽内网地址。链接读取限制并发和频率，取消任务会中止请求。平台标志图片不当作素材。

需要登录、验证、动态加载或平台限制的内容可能读不到；不会绕过登录或伪造抓取结果。公开视频链接只读取页面公开文字与封面，不下载完整视频和音轨。专门的图片篡改、AI 生图和声音伪造检测仍未接入。
